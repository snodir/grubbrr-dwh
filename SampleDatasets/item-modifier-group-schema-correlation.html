Item / modifier group — SQL schema correlation

Grubbrr menu service tables: item_master, item_modifier_group_glue, modifier_group_master, modifier_group_modifier_glue, modifier_master, modifier_nested_modifier_group_glue

What the base query does

You start from item_modifier_group_glue (img): one row means this item (or variation) uses this modifier group in this catalog, with group-level rules on the item (min_selection, max_selection, free_count, etc.).

You join modifier_group_modifier_glue (mg) on catalog_id + modifier_group_master_id. That adds every modifier option that belongs to that group (one row per modifier in the group), with per-modifier rules (min_quantity, max_quantity, is_default, …).

For filters on one catalog, one item, and one modifier group, you get one row per modifier in that group, each repeating the same img columns. That is expected.

Filtering by img.item_master_id does not change how many modifiers appear; it only ensures the item is attached to that group.

How tables relate

erDiagram item_master ||--o{ item_modifier_group_glue : "catalog_id + id = item_master_id" modifier_group_master ||--o{ item_modifier_group_glue : "catalog_id + id = modifier_group_master_id" modifier_group_master ||--o{ modifier_group_modifier_glue : "catalog_id + id = modifier_group_master_id" modifier_master ||--o{ modifier_group_modifier_glue : "catalog_id + id = modifier_master_id" modifier_master ||--o{ modifier_nested_modifier_group_glue : "modifier_master_id" modifier_group_master ||--o{ modifier_nested_modifier_group_glue : "nested group modifier_group_master_id"
  • item_master — menu item; join with im.catalog_id = img.catalog_id and im.id = img.item_master_id.
  • modifier_group_master — the group’s master record; join with mgm.catalog_id = img.catalog_id and mgm.id = img.modifier_group_master_id.
  • modifier_master — the modifier option; join with mm.catalog_id = mg.catalog_id and mm.id = mg.modifier_master_id.

modifier_nested_modifier_group_glue

That table is not part of “item → group → modifiers.” It means: on a given modifier, attach a child modifier group (modifier_master_id + modifier_group_master_id + catalog_id).

  • img ⋈ mg path = flat options for the group on the item.
  • modifier_nested_modifier_group_glue = sub-groups hanging off a specific modifier.

Example: extended query

SELECT DISTINCT
       img.catalog_id AS catalogid,
       img.item_master_id AS menuitemid,
       im.name AS item_name,
       img.modifier_group_master_id AS modifiergroupid,
       mgm.name AS modifier_group_name,
       mg.modifier_master_id AS modifierid,
       mm.name AS modifier_name,
       img.min_selection AS itm_modgrp_min_selection,
       img.max_selection AS itm_modgrp_max_selection,
       img.free_count AS itm_modgrp_free_count,
       img.is_active AS is_itm_modgrp_active,
       img.is_deleted AS is_itm_modgrp_deleted,
       img.created_on AS itm_modgrp_created_on,
       img.modified_on AS itm_modgrp_modified_on,
       img.is_invisible AS is_itm_modgrp_invisible,
       mg.is_default,
       mg.min_quantity,
       mg.max_quantity,
       mg.allow_quantity_increment,
       mg.increment_step,
       mg.default_quantity,
       mg.is_active AS is_modgrp_modfr_active,
       mg.is_deleted AS is_modgrp_modfr_deleted,
       mg.created_on AS modgrp_modfr_created_on,
       mg.modified_on AS modgrp_modfr_modified_on,
       mg.is_invisible AS is_modgrp_modfr_invisible
FROM public.item_modifier_group_glue AS img
INNER JOIN public.item_master AS im
        ON im.catalog_id = img.catalog_id
       AND im.id = img.item_master_id
INNER JOIN public.modifier_group_master AS mgm
        ON mgm.catalog_id = img.catalog_id
       AND mgm.id = img.modifier_group_master_id
INNER JOIN public.modifier_group_modifier_glue AS mg
        ON img.catalog_id = mg.catalog_id
       AND img.modifier_group_master_id = mg.modifier_group_master_id
LEFT JOIN public.modifier_master AS mm
        ON mm.catalog_id = mg.catalog_id
       AND mm.id = mg.modifier_master_id
WHERE img.catalog_id = 'catlg-72d9629f-b501-4707-84c9-cd31943837b7'
  AND img.item_master_id = 'itm-bfc98578-a9c7-4d82-a6f6-1fc187e43476'
  AND img.modifier_group_master_id = 'modgrp-58788338-8abb-4418-8fb7-1920e92dc527'
LIMIT 100;

Note: item_modifier_group_glue can use item_variation_master_id instead of item_master_id (mutually exclusive). If nothing returns, check for a variation row instead.
